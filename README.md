# HumNote

[![CI](https://github.com/RVMXL/HumNote/actions/workflows/ci.yml/badge.svg)](https://github.com/RVMXL/HumNote/actions/workflows/ci.yml) [![Release](https://github.com/RVMXL/HumNote/actions/workflows/release.yml/badge.svg)](https://github.com/RVMXL/HumNote/actions/workflows/release.yml)

**HumNote** — ментальный диктофон мелодий: напойте или просвистите мелодию —
приложение распознает ноты, выровняет их по сетке темпа и отдаст **MIDI** или
**WAV**. Работает **полностью офлайн**: запись, распознавание (YIN), синтез,
экспорт и история — всё выполняется на устройстве. Без сервера, без аккаунтов,
без аналитики — данные не покидают устройство.

## Как это работает

| Этап | Что происходит |
|---|---|
| Запись | Большая кнопка (Shazam-style): микрофон через Web Audio API, фильтры речевого диапазона 65 Гц–4.5 кГц, кадры pitch-детекции каждые 40 мс, до 60 секунд. Живо: текущая нота и уровень сигнала |
| Распознавание | Алгоритм **YIN** (de Cheveigné & Kawahara, окно 2048, параболическая интерполяция) — чистый TypeScript без внешних зависимостей; затем адаптивный noise gate по распределению громкости, медианный фильтр, сегментация с гистерезисом (вибрато и глиссандо не дробят ноту), склейка разрывов и октавная коррекция ошибок |
| Темп | BPM оценивается автоматически по медианному межнотному интервалу (фолд в диапазон 65–190) и правится слайдером 40–220 на лету |
| Квантование | Сетка 1/4 · 1/8 · 1/16 такта (по умолчанию 1/8), монофонический клэмп — ноты выравниваются по такту при смене BPM или сетки |
| Результат | Piano roll (canvas с сеткой тактов и октавными метками), плеер с тембрами Sine/Square и бегунком позиции; экспорт MIDI/WAV и системный «Поделиться» |

## Ключевые возможности

- **Полная автономность** — ни одного сетевого запроса: распознавание, синтез
  (включая офлайн-рендер WAV через OfflineAudioContext) и экспорт выполняются
  на устройстве. История набросков — localStorage (до 100 записей).
- **Экспорт MIDI** — Standard MIDI File Type-0 (PPQ 480, метасобытие темпа):
  открывается в любой DAW или piano roll редакторе; быстрый экспорт MIDI прямо
  из истории.
- **Экспорт WAV** — PCM16, 44.1 кГц, рендер синтезированной версии на устройстве.
- **«Поделиться»** — системный шит (Web Share API / @capacitor/share) с
  фолбэком на скачивание файла.
- **История набросков** — загрузка, быстрый MIDI, удаление; названия
  редактируются перед сохранением.
- **Демо-мелодия** — «Ода к радости» в один тап: попробовать piano roll,
  плеер и экспорт можно без микрофона.
- **Безопасный микрофон** — запись только после явного разрешения, сырой сигнал
  без браузерных NS/AGC (они портят свист); фильтры убирают гул и верха за
  пределами голоса; автостоп по лимиту 60 секунд.
- **8 языков интерфейса** — English, Русский, Español, Português, Français,
  Deutsch, 中文, 日本語: язык определяется автоматически и переключается в шапке.
- **Тёмная и светлая темы** — выбор в один тап, запоминается между запусками;
  по умолчанию тема подстраивается под системную.
- **Жест «назад» = шаг назад** — системная кнопка/жест Android и свайп iOS не
  сворачивают приложение, а отменяют запись или возвращают из результата
  к экрану записи.

## Скачать

Готовые сборки — в разделе **[Releases](https://github.com/RVMXL/HumNote/releases)**.
Единый выпуск собирается и публикуется CI по пушу тега `v*`. История изменений
по версиям — в [`CHANGELOG.md`](CHANGELOG.md) и примечаниях к релизам.

| Артефакт | Платформа | Что это |
|---|---|---|
| `HumNote-<ver>-android.apk` | Android 8.0+ (ARM64/ARM32/x86_64) | Приложение, работает полностью офлайн |
| `HumNote-<ver>-web.zip` / `.tar.gz` | любая ОС | Статический сайт: распакуйте и разверните на любом хостинге |

Запись в web-версии работает в Chrome/Safari по HTTPS (или на `localhost`).

## Сборка из исходников

Требуется [Bun](https://bun.sh) 1.2+ (или Node.js 20+ с npm).

```bash
bun install
bun run lint        # eslint
bunx tsc --noEmit   # строгая типизация
bun run build       # next build → статический сайт в out/
bun run dev         # режим разработки на http://localhost:3000
```

Весь аудио-движок изолирован в `src/lib/audio/` (чистый TypeScript, без
React): `yin.ts` — pitch-детекция, `analysis.ts` — пост-обработка и
квантование, `midi.ts` — SMF-писатель, `synth.ts` — синтез и WAV-рендер,
`recorder.ts` — захват микрофона.

Android: `bun run build && bunx cap sync android` → `android/` собирается в
Android Studio или `./gradlew assembleRelease` (подпись — через
`keystore.properties`, см. `.github/workflows/release.yml`).

## Android

- Подпись релизных APK — стабильным upload-ключом (RSA-4096, срок 30 лет).
  **SHA-256 сертификата:**
  `07:2D:73:DD:CE:FC:E9:66:8B:B3:81:4C:31:61:0F:43:AA:9B:28:49:5B:46:9B:3C:8C:71:77:19:76:D3:9F:1D`.
  Обновления ставятся поверх установленных версий; если установка
  предупреждает о подписи — значит, APK получен не из официального релиза.
- Ключ хранится только в GitHub Secrets репозитория; в git он не попадает
  (`.gitignore`). В CI SHA-256 ключа и отпечаток сертификата сверяются с
  пинами — подмена секрета ломает сборку, а не тихо подписывает APK чужим
  ключом. Потеря ключа = невозможность обновить приложение поверх
  установленного, поэтому резервная копия ключа — на ответственности владельца.
- Разрешения: `RECORD_AUDIO` (запись напева — основная функция) и
  `INTERNET` (требование WebView; приложение само не ходит в сеть).
- Приложение работает офлайн: WebView раздаёт упакованные ассеты локально.
