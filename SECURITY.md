# Политика безопасности HumNote

## Архитектура: сервера нет

HumNote — статическое приложение без серверной части. Распознавание нот,
синтез, экспорт MIDI/WAV и история набросков выполняются **целиком на
устройстве**:

- запись микрофона — Web Audio API внутри страницы/WebView;
- история — localStorage устройства, данные никогда не отправляются по сети;
- приложение не содержит аналитики, телеметрии, рекламы и учётных записей;
- сетевые запросы приложением не выполняются (единственное разрешение
  Android `INTERNET` — системное требование WebView).

## Ключи подписи

- Релизные APK подписываются стабильным upload-ключом (RSA-4096, срок 30 лет).
- Ключ хранится **только** в GitHub Secrets репозитория; в git он не попадает
  (`.gitignore`). В workflow SHA-256 ключа и сертификата сверяются с пинами —
  подмена секрета ломает сборку, а не тихо подписывает APK чужим ключом.
- SHA-256 сертификата подписи опубликован в README (раздел «Android») —
  сверяйте его после обновлений.

## Обновления поверх установленных

Обновления ставятся поверх старых установок, потому что все релизы
подписываются одним и тем же ключом. Если установка предупреждает о
несовпадении подписи — APK получен не из официального релиза.

## Как сообщить об уязвимости

Используйте [Security Advisories](https://github.com/RVMXL/HumNote/security/advisories/new)
или заведите issue с меткой `security` (для чувствительных деталей —
приватный advisory). Пожалуйста, не публикуйте эксплуатируемые примеры
публично до выпуска исправления.
